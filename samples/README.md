# samples/

このディレクトリには日本語 RAG パイプラインのエンドツーエンド検証用サンプル文章を配置します。
plan `docs/plans/2026-04-21-001-feat-japanese-rag-chunking-plan.md` の Unit 11 に従い、以下 6 本を作成者が執筆します:

| ファイル名          | ジャンル                 | 目標文字数  | 執筆方式                   |
|---------------------|--------------------------|-------------|----------------------------|
| `01_news.txt`       | ビジネスニュース記事      | 5,000 字    | 作成者                     |
| `02_tech.txt`       | 技術ドキュメント         | 6,000 字    | 作成者                     |
| `03_interview.txt`  | インタビュー/対談         | 5,000 字    | 作成者                     |
| `04_travel.txt`     | 旅行エッセイ             | 5,000 字    | 作成者                     |
| `05_biography.txt`  | 百科事典風 (架空歴史人物) | 4,500 字    | Claude 下書き + 作成者校正 |
| `06_fiction.txt`    | 小説抜粋                 | 4,500 字    | 作成者                     |

合計 ~30,000 字。

## 受入基準 (R25)

作成者自身が以下を目視確認:
- (a) 実在する会社名・人名・地名との偶発的衝突が無い
- (b) 文章が自然に読める (機械的な繰り返しや不自然な言い回しが無い)
- (c) 各ジャンル想定の固有名詞密度 (ジャンルごとに目視)

## expected.yaml

`samples/expected.yaml` はスモークテスト (Unit 12) の期待結果を定義します。サンプル執筆完了後に、この fixture を更新して `pytest tests/test_smoke.py` を通してください。

## 注意

6 本全てを commit する方針です (Sample #5 の Claude 下書きを含む)。社内規定は A 選択 (plan Key Decisions 参照)。
